## ⚙️ Cómo me gusta trabajar

- 💡 **Aprender haciendo:** experimentar, investigar y descubrir nuevas formas de resolver problemas.
- 🎯 **Elegir bien las herramientas:** utilizar lo que realmente necesita cada proyecto.
- ✨ **Cuidar los detalles:** prestar atención al diseño, la experiencia y el funcionamiento.
- 🧪 **Probar y mejorar:** revisar resultados, corregir errores y seguir perfeccionando.
- 🤖 **Aprovechar la IA:** utilizar herramientas como Claude Code para explorar ideas, desarrollar y optimizar mi trabajo.
- 🚀 **Construir cosas reales:** convertir ideas en proyectos que se puedan utilizar, probar y mejorar.
